# Code of conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Please read it. The short version: be decent to people, assume
they are acting in good faith, and take the heat out of a disagreement rather
than adding to it.

## Reporting

If someone's behaviour in an issue, pull request or discussion is a problem,
report it to the maintainer privately. Use the email on the
[maintainer's GitHub profile](https://github.com/prayagtushar), or open a
[private advisory](https://github.com/prayagtushar/agent-canvas/security/advisories/new)
if you would rather use a channel GitHub keeps confidential.

Reports are read by the maintainer and not shared further. You will get a reply.

## Enforcement

The maintainer may edit or delete comments, close issues and pull requests, and
block accounts, for behaviour that breaks the covenant. Serious or repeated
cases lead to a permanent ban.
